# Final QA Checklist - everything must pass before delivery

- [ ] One core idea, not everything emphasized at once
- [ ] Hierarchy is clear in the first 3 seconds
- [ ] Headline is specific and measurable
- [ ] Shows the real thing, not empty boxes
- [ ] No slop indicator remains without a reason
- [ ] Colors stay within the locked system; no default purple AI gradient
- [ ] Numbers use tabular figures
- [ ] Inner radius = outer radius - padding
- [ ] Shadows use the scene's color
- [ ] All states exist: Default / Loading / Success / Error / Empty / Disabled
- [ ] Resend / Retry / Back are present; never removed for a cleaner look
- [ ] Every button gives immediate feedback; no silent buttons
- [ ] Every animation has a purpose, not just decoration
- [ ] No layout shift while data loads
- [ ] The requester says "locked"
